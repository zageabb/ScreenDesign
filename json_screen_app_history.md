### Step 4 — Added Layout Control

Gez requested ability to control **form layout** per screen:

> “I’d like the ability to decide if fields need to be in 1 column, 2 column, or a table on each screen.”

Enhancements made:

- New schema-level UI property:  
  ```json
  "ui": { "layout": "one" } // or "two", "table"
  ```
- `renderer.js` now renders:
  - `one`: single column stack.  
  - `two`: CSS grid (2 cols) with per-field `ui.colSpan`.  
  - `table`: label/value table layout.  
- Updated `vehicle.json` and added `service_table.json` examples.
